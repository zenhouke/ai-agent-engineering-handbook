# 4.2 四个可选实验：把原理变成可观察结果

只需要 Python 3.11 或更新版本与标准库，无模型下载、API Key、付费请求或外部写操作。以下命令在仓库根目录执行。先预测输出，再运行；结果不符时检查中间量。

## 实验一：梯度下降

```sh
python3 -m labs.gradient
```

对应数学与神经网络章节。使用 `x=2, y=4` 的单样本线性模型，先打印学习率 0.1 的一次更新，再打印大步长导致损失上升的反例。验收：从 `w=1` 更新到 `w=1.8`，损失从 4 降到约 0.16；学习率 0.3 时损失约 7.84。

尝试把学习率改成 0 或负数，解释结果。这个实验展示梯度方向，不证明模型有泛化能力。

## 实验二：因果注意力

```sh
python3 -m labs.attention
```

对应 Transformer 章节。先计算两位置 softmax 与加权和，再屏蔽未来位置。验收：未屏蔽时输出约 `[1.4621, 0.5379]`；屏蔽后为 `[2,0]`，且被屏蔽位置概率为 0。若所有位置都屏蔽，函数应报告输入错误而非返回 NaN。

尝试将分数 `[1,0]` 同时加上 1000，验证稳定 softmax 的结果不变。这里没有训练网络，也没有 tokenizer。

## 实验三：权限过滤与证据评价

```sh
python3 -m labs.retrieval
```

使用虚构的关键词标签进行检索，故意设置一个报价片段、一个限制条款和另一个租户的文档。验收：跨租户片段不进入候选；只返回报价时，两个必要片段的 Recall 是 0.5，但证据齐全判定为 false；增加候选后两片段同时出现才为 true。

这个实验只演示过滤和评价分母，不是向量检索或中文分词质量基准。真实 RAG 还要处理解析、切块、embedding、混合检索与引用支持。

## 实验四：成功后崩溃与幂等恢复

```sh
python3 -m labs.recovery
```

模拟本地任务库与独立外部草稿服务。第一次外部创建后故意崩溃，未写入本地完成回执；重新打开数据库，以相同 operation_id 恢复。验收：任务从 unknown 到 completed，外部只存在一份草稿，返回相同 ID。临时目录在实验退出后清理。

这里的幂等保证来自模拟外部服务的唯一操作键，不是 SQLite 能自动替真实工具防重。若第三方服务没有幂等与查询能力，应转人工核查。
